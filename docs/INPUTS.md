# Inputs and replacement instructions

## Starting point and versions

This is an analysis replication, beginning after NF/ANS construction. Use the
OpenAlex snapshot dated 2026-09-23 and score years 2023 and 2024. Keep all score
precision; never load rounded website displays or PDF-extracted values.

Public upstream resources:

- [Opindx software v0.1.0](https://doi.org/10.5281/zenodo.23108424).
- [Opindx dataset, data-2026-09-v2](https://doi.org/10.5281/zenodo.23108621).
- [CWTS November 2023 release](https://doi.org/10.5281/zenodo.10949671), used
  for score year 2023, and [August 2024 release](https://doi.org/10.5281/zenodo.13879982),
  used for score year 2024; both CC0. Use those releases, not today's `is_core` flag.
- `data/open/leiden_scores.csv.gz`: the complete L scoring states for both
  treatments/years. `journal_id` is the effective OpenAlex scoring ISSN-L;
  `nf`, `ans` and `article_count` are full-precision values. Missing ANS remains
  missing. `is_dangling` and `is_isolated` are open-network diagnostics.

Opindx dataset mapping: `share_n_raw`, `share_n_filtered`, `share_oa_raw`,
`share_oa_filtered` provide NF, and the corresponding `per_article_...` columns
provide ANS. `issn_l` supplies the effective identity; `oa_field` supplies the
score-year rolling field. `OA` in machine-readable inputs is A in the paper.
**The website journal export omits some non-journal N-state members.** The file
`data/open/norwegian_additional_nodes.csv.gz` supplies those remaining open-input
nodes, with the same schema as the L file. Combine them with the public N export
to retain the full scoring state. No JCR or benchmark condition was used to
select these rows. Do not silently define N by the website's displayed rows.

## Restricted inputs

Supply your legitimately held 2023/2024 JCR benchmark information locally.
The package contains neither that information nor instructions to circumvent
access controls. Exact reproduction additionally needs:

1. The frozen directional, one-to-one JCR-to-effective-OpenAlex crosswalk.
2. The full J roster/base and J recursive-state scores, including missing AIS.
3. All eight J component cells for 2024 on the same frozen state.
4. The original reference-observability/Crossref sample classifications.

These inputs are **not generated by obtaining official AIS values alone**.
They can be supplied as previously computed private inputs where sharing is
authorized, or recreated by a licensed researcher from their own roster and
crosswalk using the documented scoring construction. For an upstream rebuild,
reuse Opindx's solver with the J state, corresponding edge matrices and count
vectors. For each component cell, solve with its E/T settings, then apply its
separate D denominator. No solver implementation is bundled here.

Do not submit real data to the synthetic generator. Replace its output files
in a separate private directory with the following six correctly prepared CSVs.
Keep `issn_l` as text so leading zeroes survive. Null score = undefined, never 0.
Boolean fields accept `True/False` or `1/0`.

## Exact CSV schemas

### `scores.csv`

`year, issn_l, universe, cell_id, ef, ais, a_count, is_dangling, is_isolated`

One row per full scoring-state journal/year/universe/treatment. Universes are
`J,N,OA,L`; treatments are `Raw,Filtered`. Historical internal names `ef` and
`ais` mean computed NF and ANS, **not official Clarivate values**. `a_count` is
the treatment's eligible article/review denominator count. Keep identical RAW
and REF node sets; undefined ANS is represented by a blank. Include zero scores.
No sample restriction is applied upstream to this file.

To use bundled L scores, rename `journal_id->issn_l`, `nf->ef`, `ans->ais`,
`article_count->a_count`, `treatment->cell_id`; map `RAW->Raw`, `REF->Filtered`
and add `universe=L`. The open file must never be enriched with JCR flags for
redistribution. The combined four-universe file is a private working input.

### `covariates.csv`

`year, issn_l, oa_field, a_raw, a_filtered, raw_incoming_eligible_citations, in_base_J, in_base_N, in_base_OA, in_base_L`

One row per effective identity/year covering the union of rosters, scored nodes
and benchmark matches. The `in_base_*` booleans encode pre-activity roster
membership (OA: source type journal; L: eligible dated CWTS core membership).
`a_raw`/`a_filtered` count cited-window eligible articles/reviews. The incoming
citation count is the RAW weight received **within the full J recursive
state**, after identity resolution and self-citation removal. It is therefore
restricted for package purposes. `oa_field` is the preceding-five-year modal
primary-work field used by the pinned Opindx release, with missing mapped to
`Unknown`. Do not use a journal's first source-topic field.

### `benchmark.csv`

`year, issn_l, official_ais`

One row per accepted one-to-one crosswalk match, including matches whose official
AIS is missing. Do not enter unmatched records or resolve ambiguous title matches
silently. Official zero is 0; missing is blank. This entire input stays private.

### `cube.csv`

`year, issn_l, cell_id, ais`

2024 only. Eight rows per J-state journal. Cell identifiers are `E0T0A0` through
`E1T1A1`, for all binary combinations. Historical code letter A denotes the
article denominator D in the paper. E0/T0/A0 is RAW; E1/T1/A1 is REF. `ais`
contains computed ANS. Retain missing component values; the analysis checks
that common-sample journals have all eight defined. No real rows are bundled.

### `reference_counts.csv`

`year, issn_l, publication_year, total, zero`

Score year 2024; publication years 2019–2023. For each effective journal and
publication year, count eligible cited-window articles/reviews and the subset
with no recorded OpenAlex references. These counts can be aggregated upstream
from the eligible-work table. Preserve every relevant identity, including
non-comparison journals. The package applies the computed common sample itself.
No work identifiers or raw works are required.

### `crossref_validation.csv`

`role, classification`

One row per work in the already-frozen bounded reference-observability sample.
Roles are `case` or `control`; classifications are `Crossref-positive`,
`Crossref-zero`, or `indeterminate`. These describe the archived Crossref
responses, not a new API lookup today. Crossref-zero does not establish absence
of references in the published work. Because sample selection depended on
private research inputs, no actual sample rows or selection flags are released.

### `input_manifest.json`

For empirical runs:

```json
{"mode": "empirical", "description": "Locally supplied licensed and open inputs"}
```

Keep your detailed provenance, data-access rights and crosswalk decisions in the
private input directory. The run report hashes these private inputs for local
verification; **that run report must not enter the public archive**.

## Scope of upstream evidence

Source matching, journal continuation case studies, metadata extraction totals,
CWTS membership projection, and the original bounded Crossref sample draw are
upstream preparation. This package analyses their frozen outputs. It does not
claim to recreate those decisions or rerun the OpenAlex extraction. The exact
six-file input contract makes that boundary explicit.
